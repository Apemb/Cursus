Proposition · identité visuelle

Cursus

Un manageur de workflows agentiques qui vit en tâche de fond. Son identité doit dire deux choses à la fois : un moteur qui route un graphe d'étapes, et un point qui court sur un tracé — cursus, la course.

01 · Palette

Deux registres : la marque, et l'état

L'indigo porte la marque. Le reste n'est pas décoratif : le cœur de Cursus route sur le code de sortie, alors les couleurs d'état sont une sémantique — vert qui tourne, rouge qui échoue, ambre qui attend. On ne les dépense jamais comme accent gratuit.

02 · Icône d'application

Trois pistes pour le squircle

Même grammaire — nœuds, arêtes, mouvement — trois lectures. La marque blanche se pose sur un dégradé indigo→violet, fixe dans les deux thèmes : c'est un asset produit, pas un élément d'interface.

Recommandée

Le flux

Fan-out puis join — le moteur lui-même. La plus vraie, et la meilleure à animer.

Le monogramme

Le « C » comme un tracé ouvert. Plus logo, plus lisible à très petite taille.

La course

Chevrons qui avancent vers un point-cible. Mouvement pur, l'idée de cursus.

03 · La marque retenue

Le flux — un diamant fan-out / join

Une entrée, deux branches, une jonction. C'est exactement ce que fait le noyau : une étape se divise selon le code de sortie, puis les chemins se rejoignent. L'icône est le modèle d'exécution, pas une métaphore posée dessus.

Elle se réduit proprement : à 16 px les quatre nœuds tiennent encore, et le périmètre du diamant forme une boucle fermée où le vert peut tourner quand un run est en cours.

04 · Barre de menus

Monochrome par défaut, vivante quand ça tourne

macOS veut une image-gabarit dans la barre de menus : une silhouette monochrome que le système teinte lui-même — sombre sur barre claire, claire sur barre sombre. La couleur n'y a droit qu'à un seul endroit : le point d'état. C'est notre levier « actif ».

Le flux qui tourne. Le vert remplit le tracé progressivement — nœud, arête, nœud — et le monochrome le reprend derrière : toujours une moitié verte qui avance, une moitié qui s'éteint, en rotation autour du diamant. L'animation ne tourne que pendant un run ; au repos, la silhouette redevient monochrome, sans mouvement. (Mouvement réduit respecté : l'OS la fige à mi-course — une moitié verte statique.)
